GYSApp · Motion system v1.0

Gerak yang tenang.

A reading app should feel like paper, not software. Six interaction patterns for GYSApp's hymns, Bible, and articles — one set of tokens, short distances, and a motion language quiet enough to read through.

01 · Prinsip

Five rules, one temperament

The app is read in bed, on a train, before a service. Motion has to answer quickly, then get out of the way. These five rules decide every duration and easing below.

01

Purposeful

Motion confirms a change the reader just made — a tab, a verse, the queue. If nothing changed, nothing moves.

02

Fast

Press feedback lands in 120 ms. Entrances finish by 260 ms. Reading never waits for an animation.

03

Continuous

The tab pill travels, the dock grows from its handle, verses slide the way the page reads. Objects keep their identity between states.

04

Interruptible

Every transition yields to the next input. A second tab redirects the pill; closing the dock mid-rise reverses it.

05

Quiet

Short distances, soft contrast, one accent. Motion is felt as responsiveness, not as spectacle.

02 · Token

One set of numbers

Every demo on this page reads from these declarations. Copy the whole block into the app's :root; do not introduce a local duration beside it.

Duration ladder

--motion-fast 120 ms
--motion-base 180 ms
--motion-entrance 220 ms
--motion-slow 260 ms
--motion-slower 320 ms

Press → 120 · tabs and disclosure → 180 · cards and rows → 220 · dock → 260 · page theme → 180–320.

Easing curves

Standard (.2, 0, 0, 1)
Entrance (.16, 1, .3, 1)
Exit (.4, 0, 1, 1)

motion.css 
/* GYSApp motion tokens — the only motion values */
:root {
  /* duration */
  --motion-fast: 120ms;      /* press */
  --motion-base: 180ms;      /* tabs, dialog */
  --motion-entrance: 220ms;  /* cards, rows */
  --motion-slow: 260ms;      /* dock, sheet */
  --motion-slower: 320ms;    /* page */

  /* easing */
  --motion-ease-standard: cubic-bezier(0.2, 0, 0, 1);
  --motion-ease-entrance: cubic-bezier(0.16, 1, 0.3, 1);
  --motion-ease-exit: cubic-bezier(0.4, 0, 1, 1);

  /* rhythm */
  --motion-stagger: 40ms;
  --motion-stagger-tight: 24ms;

  /* distance */
  --motion-distance-xs: 4px;
  --motion-distance-sm: 6px;
  --motion-distance: 8px;
  --motion-distance-lg: 12px;
  --motion-lift: -2px;

  /* press */
  --motion-press-soft: 0.995;
  --motion-press: 0.96;
}

      entrance.css 
      /* One entrance, reused everywhere. `backwards`
   keeps hover transforms free after the run. */
@keyframes enter {
  from { opacity: 0; transform: translateY(var(--motion-distance)); }
}

.enter {
  animation: enter var(--motion-entrance) var(--motion-ease-entrance) backwards;
}

.stagger > * {
  animation: enter var(--motion-entrance) var(--motion-ease-entrance) backwards;
  animation-delay: calc(var(--i, 0) * var(--motion-stagger));
}

/* Cap the choreography. Never animate a long list. */
.stagger > :nth-child(n + 13) { animation: none; }

.press {
  transition: transform var(--motion-fast) var(--motion-ease-standard);
}
.press:active { transform: scale(var(--motion-press-soft)); }
      tabs.js 
      function movePill(pill, tab, tabs) {
  const first = pill.getBoundingClientRect();
  const box = tabs.getBoundingClientRect();
  const target = tab.getBoundingClientRect();

  pill.style.width = target.width + 'px';
  pill.style.left = (target.left - box.left) + 'px';

  const last = pill.getBoundingClientRect();
  pill.animate(
    [{ transform: `translateX(${first.left - last.left}px) scaleX(${first.width / last.width})` },
     { transform: 'none' }],
    { duration: 180, easing: 'cubic-bezier(0.2, 0, 0, 1)' }
  );
}

      reduced.css 
      @media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 120ms !important;
    animation-delay: 0ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 120ms !important;
    transition-property: opacity !important;
    scroll-behavior: auto !important;

    /* no travel, no scale, no rotation */
    transform: none !important;
  }
}

/* A switch still has to show its state: position the
   knob with inset, which is not a transition. */
@media (prefers-reduced-motion: reduce) {
  .switch[aria-checked="true"] .switch-knob {
    inset-inline-start: 18px;
  }
}

      05 · Batas

      What stays still

      A motion system is also a list of refusals. These four are out of scope for GYSApp, regardless of how good they look in a dribbble shot.

      No bouncing cards

      Overshoot makes a reading surface feel like a toy. Press is 0.995, with no spring and no wobble.

      No parallax on text

      Text that drifts while scrolling forces the eye to re-fixate. The sheet stays still; only the verse changes.

      No entrance on every scroll

      One-time reveals at most, and only for new content. Re-triggering a section as it passes is a slideshow, not a reading app.

      No infinite loops

      Only the existing loading skeleton may shimmer. Nothing else repeats; a loop competes with the words on the page.

      Also out: animating width, height, top, left, or background-color. The only geometry exception in this system is the sidebar rail's grid-template-columns; everything else travels with transforms and fades with opacity.
