# Size, literature and settings follow-up — 2026-10-08

## Packaging experiment

The current native release already uses full LTO, Rust `z`, stripped symbols,
R8/resource shrinking, compressed ARM64 JNI libraries, compact lossless
SQLite/PDF assets and a 64 MiB solid NSIS dictionary. Those settings and all
bundled/offline capabilities are retained.

A payload-only experiment compared sorted concatenations of the 133 web build
files, using per-file Brotli quality 9 and Python raw LZMA1 (`dict_size=64 MiB`,
`lc=3`, `lp=0`, `pb=2`, `mode=NORMAL`, `nice_len=273`, `mf=BT4`).

| Payload                              | Before outer compression | Solid LZMA bytes |
| ------------------------------------ | -----------------------: | ---------------: |
| Raw files                            |               54,040,405 |       26,721,221 |
| Individually Brotli-compressed files |               29,919,525 |       30,211,590 |

Skipping inner Brotli could save 3,490,369 bytes in this synthetic compressed
payload, while increasing embedded/installed assets by 24,120,880 bytes.
This is **not an APK/EXE measurement**, excludes executable/archive overhead,
and does not prove a runtime speedup. Keep Tauri compression: an installed-size
regression does not meet the requested overall size/performance goal. No
capabilities, soundfont, fonts, source database, fallback plugins or quality
are removed. No new native release was requested or generated for this slice.

## Literature root cause and transport

The deployed production Worker returns `400 Unknown content kind` for
`/content/pdf-source` and `403 PDF source is not allowlisted` for the current
publisher's official S3 PDFs. Direct S3 responses lack browser ACAO headers.
Changing frontend button behavior cannot solve that deployed backend mismatch.
The existing Worker workflow completed its prerequisite check but skipped
Deploy because its Cloudflare secrets are unavailable. The user explicitly
requested finishing code first and deploying later.

Source already validates current official TJC/S3 paths. This follow-up prefers
the upload CDN for WordPress upload links, gives each connection an eight-second
header timeout, cancels failed bodies and preserves successful streaming,
range/status/CORS headers and request cancellation. PDF modules preload while
issue metadata resolves. A separate finite-range quota avoids exhausting
ordinary account/API capacity; coalesced ranges up to 8 MiB are supported.
512 KiB chunks reduce round trips without eager whole-book download. Chord
synchronization prefers its immutable CDN and retains SHA/cache verification
and its pinned proxy fallback.

Real-publication browser probe used Chromium at 1280×800, a local Node adapter
running the built Hono app, and the environment's outbound proxy. External
background artwork/music was blocked to isolate PDF transport/rendering;
public PDF and minimal WordPress metadata remained live. Service workers were
blocked, each document used a new browser context. The Node probe sets a
Mozilla UA for the environment proxy; local Workerd outbound requests were
unavailable here. This is local end-to-end evidence, **not production Worker
or packaged-device deployment validation**.

| Publication                         | Total source bytes | First canvas | Range requests | Completed transfer bytes |
| ----------------------------------- | -----------------: | -----------: | -------------: | -----------------------: |
| Warta Sejati, activities bulletin 4 |         90,868,320 |    10,146 ms |             12 |                8,043,009 |
| Pelita Kecil 46                     |          2,917,032 |     7,104 ms |              5 |                2,922,095 |

Transfer figures include HTTP overhead on completed PDF requests; the initial
stream can be cancelled by PDF.js. Cold publisher/network/large-image decode
latency remains real, so “instant” is not a guarantee for uncached remote PDFs.
The large Warta publication renders without downloading its whole document.

## Structure and settings

- Presentation becomes one in-memory session value rather than serialized
  per-song persistent preferences. Normal mode navigation drops the query;
  reload starts text. Explicit mode deep links remain supported. Durable
  typography, chord visibility, PDF progress and reset behavior remain separate.
- The proxy's connection/fallback policy moves into a focused helper, retaining
  boundary validation and response handling in the existing Worker router.
- Accent, offline diagnostics and device maintenance are plain sections inside
  the existing animated top-level disclosures. Reset keeps its confirmation.
- Existing lazy route/data ownership, incremental hash-based chord caching,
  bounded PDF document leases and canvas virtualization are retained. No broad
  rewrite or dependency fork is required for these fixes.

## Verification

Tests first exposed legacy mode persistence, per-request quota collisions,
coalesced-range rejection and same-commit CDN/proxy ordering. Targeted unit
checks then passed; browser checks cover reload/session mode, saved typography,
PDF progress, offline score reuse, settings reset cancellation, responsive
localized settings, shared zoom/pan/spread behavior and seamless score changes.
Production literature still needs the deferred Worker deployment. Packaging
compression measurements are exploratory; published artifacts remain those
of `v0.1.0-preview.20261008.1`.
