## 2. Aturan pemilik yang mengikat

1. **Hosted untuk yang berat, lokal untuk yang cepat** (pemilik, 10 Nov,
   mode kreator). Jalur cepat lokal: `pnpm check:fast` — Prettier pada file yang
   berubah, typecheck web, dan unit file yang menutupinya; ±2–3 detik, sudah
   terbukti (format 671 ms, typecheck 1 103 ms). Suites penuh, kontrak browser,
   visual, axe, perf, build, soak, bundle tetap di Actions. Menjalankan hal
   berat secara lokal **diperbolehkan** bila jelas lebih cepat dan device tidak
   keberatan, lewat `GYS_ALLOW_LOCAL_HEAVY=1` (`scripts/local-heavy-guard.mjs`
   tetap menjaga default-nya).
2. **Jangan menunggu di foreground.** Dispatch workflow, lalu kerjakan item lain;
   baca hasil dengan poll `gh api .../runs/<id>` (bukan `gh run watch`, karena
   kadang `unexpected EOF`).
3. **Bukti harus jujur**: sebut run id/job/artifact hosted; bedakan unit vs
   browser vs hosted vs native (soak APK). Jangan mengklaim verifikasi lokal yang
   tidak dijalankan.
4. **Baseline visual hanya dari artefak CI.** Adopsi file PNG dari job
   `update-visual-baselines` setelah memeriksa isinya, jangan pernah dari
   screenshot lokal.
5. **Kualitas UI adalah bagian goal**: target sentuh ≥44 px, kontras ≥4,5:1,
   satu `h1`, radius 6/8/10/12/16/24/999, skala tipe 13 langkah, spacing 2 px,
   tema light/dark/sepia/amoled, hormati `prefers-reduced-motion`.
6. **Desain UI dari OpenDesign, kontinu.** Setiap peningkatan desain diambil
   dari artefak OpenDesign; rotasi: Beranda → Kidung → Alkitab → Iman →
   Literatur → Suara → Lainnya/pengaturan → dialog/sheet, lalu ulang.
7. **Rilis APK tiap 25 putaran.** Berikutnya **putaran 251**. Alur ada di
   `docs/plans/release-cadence.md`, penanda di `.github/release-cadence.json`.
   APK masih **debug signing** (pratinjau, bukan Play Store).
8. **Jangan menjalankan browser lokal** (Chromium/Playwright) — device ini
   dipakai untuk melihat preview saja.
9. **Bahasa dan arsitektur boleh berubah kalau alasannya terukur** (pemilik,
   10 Nov). Menambah/mengganti bahasa di frontend, backend, BFF, native, atau
   perkakas (mis. Rust untuk backend, pustaka React tambahan, formulasi bahasa
   lain) **diperbolehkan** asalkan hasilnya tetap bisa dipaketkan konsisten
   untuk semua device dengan fitur yang sama: satu build web, satu APK Android,
   satu shell native, tanpa fitur yang cuma ada di satu jalur. Tulis alasan dan
   batas paketnya di commit atau catatan putaran.
10. **Mode kreator: tiap putaran mengoptimalkan harness.** Selama goal ini
    berjalan, setiap putaran menyisipkan satu perbaikan kecil pada harness
    (skrip, seleksi test, kecepatan umpan balik, kemudahan debugging) sampai
    tidak ada lagi yang terukur. Fokusnya performa dan kemudahan debug, bukan
    menambah tool baru yang tidak dipakai.

### 7d. Edge TTS v2 dan kenapa web masih 503 (10 Nov, putaran 4)

Microsoft mengganti token handshake read-aloud pada Oktober 2026: `Sec-MS-GEC`
bukan lagi SHA-256 biasa (`1-<versi>`), melainkan `<cs64>-<sha256>` dengan judul
versi `2-<versi>`. `apps/web/src/edge-ms-gec.ts` memuat port dari edge-tts 7.3.1
(`src/edge_tts/drm.py`), dan `apps/web/src/edge-ms-gec.test.ts` menyimpan tiga
token referensi hasil implementasi Python itu — jadi salah ketik konstanta
langsung merah di unit test.

Bukti kecocokan: token untuk `1762819200`, `1762819500`, `1735689600.5`, dan
`1789084800` identik dengan keluaran Python (dicek lokal sebelum port, lalu
dikunci di test).

Web belum bisa memakai jalur langsung: browser tidak boleh mengatur header
(`Cookie`, `Origin`, UA) yang diwajibkan Microsoft, dan WebSocket lintas-origin
tidak membawa kredensial itu. Karena itu jalur web selalu lewat BFF:
`apps/bff/src/index.ts` `POST /api/v1/tts/edge` membutuhkan `EDGE_TTS_URL`
(relay milik sendiri) atau `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION`. Di
produksi keduanya kosong, sehingga jawabannya `503 UPSTREAM_UNAVAILABLE
"Edge compatibility speech is not configured"` — itu penyebab "Edge TTS belum
bekerja" di web, bukan bug klien.

Pelafalan "Allah": `apps/web/src/speech-pronunciation.ts` menyisipkan jeda suku
kata (`Al-lah`) hanya untuk suara perangkat/offline, karena mesin TTS Android
membacanya dengan tekanan Arab ("Auoloh"). Suara cloud tidak diubah. Kontrak:
`apps/web/src/speech-pronunciation.test.ts`.

Overlay login e-GYS: `open_egys_login` di `apps/native/src-tauri/src/lib.rs:344`
SUDAH membuka jendela WebView di dalam aplikasi (`WebviewWindowBuilder`, 480×760,
dengan `EGYS_LOGIN_BRIDGE_SCRIPT`). Jadi "harus muncul overlay" secara teknis
sudah ada; yang tersisa adalah kebijakan Google yang menolak OAuth di WebView
(`disallowed_useragent`). Jalan yang sah: Chrome Custom Tabs di Android (tetap
permukaan di dalam aplikasi, bukan browser penuh) atau tetap browser sistem.
Jangan mengakali user-agent.

### 7e. Relay Edge TTS di Worker — web akhirnya berbunyi (10 Nov, putaran 5)

Web tidak bisa membuka socket Microsoft sendiri (header `Origin`/UA/cookie
dilarang, dan WebSocket lintas-origin tidak membawa kredensial). Solusinya:
Worker yang membuka socket itu untuk satu ucapan, lalu mengembalikan `audio/mpeg`
biasa ke browser. Tidak perlu secret baru, tidak perlu relay yang di-host
sendiri.

- `apps/bff/src/edge-relay.ts`: handshake (`Upgrade: websocket` lewat `fetch`,
  **URL harus `https:`** — Worker menolak `wss:`), frame `Path:speech.config`
  lalu `Path:ssml`, pembacaan paket biner `[2 byte panjang header][header][audio]`,
  berhenti di `Path:turn.end`, batas 20 s / 10 MB.
- `apps/bff/src/edge-ms-gec.ts` adalah salinan `apps/web/src/edge-ms-gec.ts`
  (Worker tidak bisa mengimpor sumber app lain); test token referensi yang sama
  menjaga kedua salinan tetap identik.
- `apps/bff/src/index.ts` `POST /api/v1/tts/edge`: bila `EDGE_TTS_URL` dan Azure
  kosong, Worker menyintesis sendiri. `EDGE_RELAY=off` mengembalikan perilaku
  lama (503) sebagai jalan mundur.
- Jebakan yang tertangkap: paket biner di runtime datang sebagai **Blob**, bukan
  ArrayBuffer; `new Uint8Array(blob)` menghasilkan panjang 0 tanpa error, jadi
  audio tampak "kosong" padahal 20 paket masuk. Normalisasi dulu, baru baca
  header. Pesan galat sekarang menyebut jumlah frame teks/biner yang diterima.

Bukti hosted: `Cloudflare Worker` deploy run `42859059222` dan sesudah perbaikan
Blob; probe produksi
`POST https://gysapp-tauri-bff.pas-presensi.workers.dev/api/v1/tts/edge`
→ `200`, `20 880` byte, `0.79 s`, `MPEG ADTS layer III 48 kbps 24 kHz`
(preflight `204`, `access-control-allow-origin: https://gyspnk.github.io`).
Probe keyless langsung dari mesin ini juga lulus:
`Edge keyless TTS live smoke passed: 17568 audio bytes in 1600ms` — jadi B-35
(403 untuk semua build Edge) memang selesai oleh token v2.

### 7f. Login Google di native tetap di dalam overlay (10 Nov, putaran 6)

`open_egys_login` memang sudah membuka jendela WebView milik aplikasi
(`apps/native/src-tauri/src/lib.rs:344`, 480×760, `EGYS_LOGIN_BRIDGE_SCRIPT`),
jadi overlay-nya bukan hal baru. Yang salah adalah popup: tombol Google bisa
membuka `accounts.google.com` sebagai jendela baru, dan di Android jendela baru
itu berakhir di browser sistem — keluar dari aplikasi, persis yang diminta
jangan terjadi.

- `egys_popup_action(url)` sekarang memutuskan tiga hal: `SameWindow` (host yang
  diizinkan: e-GYS, Google, Apple), `External` (WhatsApp lewat shell), `Deny`.
- `SameWindow` dipanggil dengan `login.navigate(url)` di jendela login yang sudah
  ada, jadi langkah Google tetap di overlay; `NewWindowResponse` selalu `Deny`.
- Test Rust `the_google_step_stays_inside_the_overlay_window` mengunci empat
  kasus: Google → same window, e-GYS → same window, `https://wa.me/...` →
  external, host asing dan `http://` → deny.

Batas jujur yang masih berlaku: Google menolak OAuth di WebView yang ditandai
`wv` (`disallowed_useragent`). Kalau halaman Google menolak, solusi resminya
Chrome Custom Tabs atau browser sistem — bukan menyamarkan user-agent. Overlay
tetap dipakai untuk seluruh alur e-GYS; yang tidak boleh dilakukan adalah
memalsukan UA agar Google menerima.

### 7h. Ketukan cepat berhenti menumpuk riwayat (10 Nov, putaran 7)

`page-transitions.spec.ts` sesekali merah: dua ketukan cepat ke dua rute
meninggalkan dua entri riwayat, jadi `goBack()` mendarat di rute yang sudah
ditinggalkan. Penyebabnya `navigateSmooth` hanya membatalkan navigasi lama
(`navigationGeneration`), tanpa memberi tahu router bahwa entri barunya harus
**menggantikan** yang tertunda.

- Perilaku yang dikunci: ketukan kedua tidak menumpuk riwayat, `goBack()` dari

- Bukti hosted: `gh workflow run ci.yml -f full=true` pada `40f33c8` = run

## 8. Jebakan yang sudah memakan waktu (jangan diulang)

- Tombol Google: GIS bisa merender kotak yang _tampak_ hidup tapi tidak
  melakukan apa pun (origin belum terdaftar). Karena itu `renderButton` wajib
  menghasilkan kontrol yang punya ukuran, dan tekan yang tidak membuka jendela
  maupun memblokir popup harus menjadi pesan (`more.googlePressSilent`), bukan
  diam. Kontrak: `apps/web/e2e/egys-v1.spec.ts` “answers a press with silence”.
- Tema default **tetap biru GYS** (`--blue: #00719c`, `--blue-soft: #e3f2fa`,
  `--navy: #163f61`), dan preset akse pertama adalah “Biru GYS”. Palet editorial
  tidak boleh menimpa identitas itu; ia masuk lewat tema/akse, bukan `:root`.

- **Kunci i18n harus di tiga locale.** `src/i18n.test.ts` membandingkan set kunci
  id/en/zh; menambah di satu file membuat CI merah.
- **Skala spacing**: nilai >24 px wajib kelipatan 4 (`spacing-scale.test.ts`).
- **`dist/` harus dibangun ulang** sebelum preview memuat perubahan; jangan
  membangun saat run browser berjalan.
- **Visual spec & fokus**: cincin fokus 3 px bisa mengubah snapshot pembaca;
  spec direct-reader sekarang memblur elemen aktif sebelum screenshot.
- **`gh run watch`** kadang `unexpected EOF`; polling `gh api` lebih andal.
- **Push bisa gagal** karena pre-push hook kehabisan memori; ulangi push.
- **Animasi**: jangan animasikan layout (`width/height/top`); pakai
  opacity/transform, durasi token `--motion-*`, dan sediakan reduced-motion.
- **Jangan** menyimpulkan hasil dari satu sampel perf: variance runner ±30 %,
  pakai median ≥3 atau bandingkan dalam satu run.
- **`-f full=true` sampai `2527eba` tidak menjalankan suite apa pun** (gate
  keluar 0 lewat cabang "baseline regeneration"). Sekarang ia menjalankan empat
  shard; buktinya job `e2e-shard (1..4)`, bukan kesimpulan run.
- **Format bisa merah oleh commit sesi lain** (`--no-verify` melewati hook).
  `pnpm exec prettier --check .` memakan ≈3 dtk dan menamai file yang salah.
- **Jangan menulis hex palet di e2e.** `apps/web/e2e/theme-tokens.ts` membaca
  token; palet dan kontrasnya dijaga `apps/web/src/editorial-palette.test.ts`.
- **`pnpm verify --explain <runId>`** mencetak job/step/baris log penyebab —
  pakai itu sebelum mengunduh log penuh.
- **Seleksi e2e bisa menyembunyikan spec, bukan hanya melewatkannya.**
  `app-design.css` tidak pernah memilih `ui-polish.spec.ts`/
  `home-resilience.spec.ts`, jadi kontrak Sauh di sana merah berhari-hari tanpa
  ada run yang menjalankannya (terbukti di sweep `42823812789`). Sejak
  `scripts/test-e2e-selective-core.mjs` mereka ikut terpilih untuk lembar desain
  bersama. Kalau sebuah spec hanya muncul saat file spec itu sendiri diubah,
  periksa peta seleksinya.
- **Jangan bandingkan tinggi kotak dengan angka tebakan.** Kontrak Sauh menulis
  `abs(media.height - panel.height) < 1`, padahal di bawah 720 px media memang
  pita tipis dan dari 720 px ia absolut menutup panel. Ukur proporsi
  (`media.height < panel.height * 0.6` di ponsel) atau bagi per breakpoint.
- **Kartu rak adalah flex item yang di-stretch**: `height: 100%` pada
  `.suara-card-media` mengalahkan `aspect-ratio`, jadi rasio 2:3 dipegang kotak
  padding (`height: 0; padding-bottom: 150%`), bukan `aspect-ratio`.
- **CLS diukur lewat lane `perf`, bukan tebakan.** `gh workflow run ci.yml -f
perf=true` menjalankan `instant-navigation.spec.ts --grep @perf` lalu
  `runtime-performance-baseline.spec.ts --grep "primary routes"`; baris
  `[perf-row]` memuat `layoutShift` dan `layoutShiftSources` per rute. Jalur itu
  dibuat karena `perf-budget` dulu hanya jalan di `full=true` (12 menit, merah
  oleh baseline visual sesi lain). Dispatch `perf=true` kini tidak lagi memicu
  `update-visual-baselines`, dan gerbang `e2e` menuntut `perf-budget` hijau
  untuk jalur itu — kalau tidak, dispatch yang hanya mengukur bisa lolos lewat
  cabang "baseline regeneration".
- **CLS Literatur berasal dari rak unggulan yang muncul belakangan.**
  `42837923030` mencatat `div.literature-sections moved` +53 px di ponsel dengan
  `layoutShift` 0,0173 (tablet 0,0117, desktop 0,0058). Selama `loading`, halaman
  sekarang merender kerangka rak dengan baris dan kotak sampul yang sama
  (`.literature-cover-skeleton`, `.skeleton-bar`) supaya bagian di bawahnya tidak
  ikut bergeser.
