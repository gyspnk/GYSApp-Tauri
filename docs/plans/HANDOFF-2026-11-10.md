Dokumen ini untuk melanjutkan goal otonom di **mesin lain**. Semua fakta di
bawah diambil dari repo, run GitHub Actions, dan rilis yang benar-benar ada,

## 1. Apa yang sedang dikerjakan

BFF Cloudflare Worker, paket data offline, build android/Tauri) sambil menjaga
kualitas UI, performa, aksesibilitas, dan bukti hosted. Pekerjaan berjalan
**langsung di `main`** (tanpa PR), commit atas nama
`KernelXtream <thengilbert@gmail.com>`.

- Repo: `https://github.com/gyspnk/GYSApp-Tauri`
- Branch kerja: `main`
- Sumber kebenaran rinci: `docs/plans/2026-10-30-autonomous-development-handoff.md`
  (565 KB, berisi riwayat tiap putaran, angka sebelum→sesudah, dan keputusan).
- Putaran terakhir saat handoff: **229/256**.

## 2. Aturan pemilik yang mengikat

1. **Semua proses di GitHub Actions.** Di mesin lokal hanya boleh menjalankan
   server web: `pnpm dev` (127.0.0.1:5173) dan `pnpm preview` (127.0.0.1:4173).
   Typecheck, unit, build, e2e, visual, axe, perf, soak native, bundle, docs,
   format harus lewat Actions. Script lokal sudah dipagari
   `scripts/local-heavy-guard.mjs` (escape hatch: `GYS_ALLOW_LOCAL_HEAVY=1`).
2. **Jangan menunggu di foreground.** Dispatch workflow, lalu kerjakan item lain;
   baca hasil dengan poll `gh api .../runs/<id>` (bukan `gh run watch`, karena
   kadang `unexpected EOF`).
3. **Bukti harus jujur**: sebut run id/job/artifact hosted; bedakan unit vs
   browser vs hosted vs native (soak APK). Jangan mengklaim verifikasi lokal yang
   tidak dijalankan.
4. **Baseline visual hanya dari artefak CI.** Adopsi file PNG dari job
   `update-visual-baselines` setelah memeriksa isinya, jangan pernah dari
   screenshot lokal.
5. **Kualitas UI adalah bagian goal**: target sentuh ≥44 px, kontras ≥4,5:1,
   satu `h1`, radius 6/8/10/12/16/24/999, skala tipe 13 langkah, spacing 2 px,
   tema light/dark/sepia/amoled, hormati `prefers-reduced-motion`.
6. **Desain UI dari OpenDesign, kontinu.** Setiap peningkatan desain diambil
   dari artefak OpenDesign; rotasi: Beranda → Kidung → Alkitab → Iman →
   Literatur → Suara → Lainnya/pengaturan → dialog/sheet, lalu ulang.
7. **Rilis APK tiap 25 putaran.** Berikutnya **putaran 251**. Alur ada di
   `docs/plans/release-cadence.md`, penanda di `.github/release-cadence.json`.
   APK masih **debug signing** (pratinjau, bukan Play Store).
8. **Jangan menjalankan browser lokal** (Chromium/Playwright) — device ini
   dipakai untuk melihat preview saja.

## 7. Alur kerja harian

```bash
# verifikasi hosted untuk commit terakhir (tunggu hasil, exit code = verdict)
pnpm verify --wait

# suite penuh + regenerasi baseline visual
gh workflow run ci.yml --ref main -f full=true

# screenshot QA (semua breakpoint/tema)
gh workflow run ci.yml --ref main -f qa=true -f qa_themes=light,dark -f qa_widths=320,390,768,1440

# ukur performa (rute + navigasi)
gh workflow run perf.yml --ref main

# soak native Windows
gh workflow run edge-tts-native.yml --ref main -f samples=5

# rilis APK sesuai kadensi
gh workflow run android-release.yml --ref main
```

Setelah run selesai: `gh run download <run> -n <artifact> -D <dir>`, bandingkan
PNG dengan tree, baru commit adopsi baseline.

## 8. Jebakan yang sudah memakan waktu (jangan diulang)

- **Kunci i18n harus di tiga locale.** `src/i18n.test.ts` membandingkan set kunci
  id/en/zh; menambah di satu file membuat CI merah.
- **Skala spacing**: nilai >24 px wajib kelipatan 4 (`spacing-scale.test.ts`).
- **`dist/` harus dibangun ulang** sebelum preview memuat perubahan; jangan
  membangun saat run browser berjalan.
- **Visual spec & fokus**: cincin fokus 3 px bisa mengubah snapshot pembaca;
  spec direct-reader sekarang memblur elemen aktif sebelum screenshot.
- **`gh run watch`** kadang `unexpected EOF`; polling `gh api` lebih andal.
- **Push bisa gagal** karena pre-push hook kehabisan memori; ulangi push.
- **Animasi**: jangan animasikan layout (`width/height/top`); pakai
  opacity/transform, durasi token `--motion-*`, dan sediakan reduced-motion.
- **Jangan** menyimpulkan hasil dari satu sampel perf: variance runner ±30 %,
  pakai median ≥3 atau bandingkan dalam satu run.
- **`-f full=true` sampai `2527eba` tidak menjalankan suite apa pun** (gate
  keluar 0 lewat cabang "baseline regeneration"). Sekarang ia menjalankan empat
  shard; buktinya job `e2e-shard (1..4)`, bukan kesimpulan run.
- **Format bisa merah oleh commit sesi lain** (`--no-verify` melewati hook).
  `pnpm exec prettier --check .` memakan ≈3 dtk dan menamai file yang salah.
- **Jangan menulis hex palet di e2e.** `apps/web/e2e/theme-tokens.ts` membaca
  token; palet dan kontrasnya dijaga `apps/web/src/editorial-palette.test.ts`.
- **`pnpm verify --explain <runId>`** mencetak job/step/baris log penyebab —
  pakai itu sebelum mengunduh log penuh.
- **Seleksi e2e bisa menyembunyikan spec, bukan hanya melewatkannya.**
  `app-design.css` tidak pernah memilih `ui-polish.spec.ts`/
  `home-resilience.spec.ts`, jadi kontrak Sauh di sana merah berhari-hari tanpa
  ada run yang menjalankannya (terbukti di sweep `42823812789`). Sejak
  `scripts/test-e2e-selective-core.mjs` mereka ikut terpilih untuk lembar desain
  bersama. Kalau sebuah spec hanya muncul saat file spec itu sendiri diubah,
  periksa peta seleksinya.
- **Jangan bandingkan tinggi kotak dengan angka tebakan.** Kontrak Sauh menulis
  `abs(media.height - panel.height) < 1`, padahal di bawah 720 px media memang
  pita tipis dan dari 720 px ia absolut menutup panel. Ukur proporsi
  (`media.height < panel.height * 0.6` di ponsel) atau bagi per breakpoint.
- **Kartu rak adalah flex item yang di-stretch**: `height: 100%` pada
  `.suara-card-media` mengalahkan `aspect-ratio`, jadi rasio 2:3 dipegang kotak
  padding (`height: 0; padding-bottom: 150%`), bukan `aspect-ratio`.
- **CLS diukur lewat lane `perf`, bukan tebakan.** `gh workflow run ci.yml -f
perf=true` menjalankan `instant-navigation.spec.ts --grep @perf` lalu
  `runtime-performance-baseline.spec.ts --grep "primary routes"`; baris
  `[perf-row]` memuat `layoutShift` dan `layoutShiftSources` per rute. Jalur itu
  dibuat karena `perf-budget` dulu hanya jalan di `full=true` (12 menit, merah
  oleh baseline visual sesi lain).
- **CLS Literatur berasal dari rak unggulan yang muncul belakangan.**
  `42837923030` mencatat `div.literature-sections moved` +53 px di ponsel dengan
  `layoutShift` 0,0173 (tablet 0,0117, desktop 0,0058). Selama `loading`, halaman
  sekarang merender kerangka rak dengan baris dan kotak sampul yang sama
  (`.literature-cover-skeleton`, `.skeleton-bar`) supaya bagian di bawahnya tidak
  ikut bergeser.
