This matrix records evidence against the pinned upstream revision. `PARITY`
means the named behavior was exercised against source-backed data and a check;
`FIXED` means this slice corrected a verified defect; `PARTIAL` means behavior
exists but the full upstream/runtime/device acceptance is still open;
`INTENTIONAL_DIVERGENCE` records an explicit product or platform difference;
`BLOCKED_EXTERNAL` requires a protected provider, credential, or release
environment that is not available in this local audit.

## Intentional divergences

- Browser/PWA cannot set the compatibility headers required by the direct Edge
  WebSocket. `auto` uses system speech there; `local` is the explicit offline
  choice. Direct keyless Edge transport is enabled in actual Tauri. This is
  documented as platform behavior, not upstream parity.
- The application keeps a shared media surface and global appearance system
  instead of cloning each upstream page's layout controls. Existing queue and
  reading state remain app-owned.
- The offline pack carries the catalog and verified asset metadata; most music
  binaries are fetched and integrity-checked on demand. A single PDF seed is
  bundled locally.
