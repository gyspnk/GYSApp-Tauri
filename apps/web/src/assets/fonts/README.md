# Bundled editorial fonts

These variable WOFF2 fonts are part of the offline application. They have no
runtime dependency on Google Fonts. `provenance.json` pins the upstream Google
Fonts commit, original TTF SHA-256 values, generated byte hashes, tool versions
and the accompanying SIL Open Font License files.

- GYS Reading Sans is a renamed subset of Source Sans 3. Adobe reserves the name
  "Source", so the derivative's internal family and PostScript names are changed.
- Source Serif 4 has normal and italic faces so scripture emphasis is retained.
- Noto Serif SC covers the Chinese characters used by the checked-in UI. Other
  characters in user content fall back to available system fonts.

Regenerate from the repository root with Python, `fonttools==4.61.1`, and
`brotli==1.2.0` installed:

```sh
python scripts/generate-editorial-fonts.py
pnpm exec prettier --write apps/web/src/assets/fonts/provenance.json
pnpm verify:generated
pnpm build
pnpm verify:native-assets
```

The generator checks the pinned source bytes before processing and preserves
font timestamps for reproducible output. Latin subsets retain extended Latin,
punctuation, currency symbols and layout features. Add Chinese UI copy before
regenerating the subset. Commit the generated fonts, licenses and provenance
together. Builds include all four emitted fonts in the versioned shell manifest;
the service worker verifies their exact bytes before activating an offline shell.
Packaging checks verify the same hashes in the Tauri frontend bundle.
