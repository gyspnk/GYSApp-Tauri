# Dasar Kepercayaan PDFs

Official Indonesian doctrine booklets published by Gereja Yesus Sejati / True
Jesus Church, copied unchanged from the TJC upload URLs listed in manifest.json
on 6 October 2026. The manifest records each source, byte size and SHA-256.

These documents are served locally to avoid cross-origin PDF failures in web,
PWA and native builds. They load on demand and are excluded from startup
precache. Publisher attribution and source links remain inside the documents
and in the reader's source menu.
